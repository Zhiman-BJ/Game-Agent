# Pipeline contract

## Source allocation

Pin source commit, project subdirectory and engine version. Allocate candidate slots once, keep a repository brief and semantic feature claims. Source size guides exploration capacity; it does not establish task difficulty. Related repositories and derived projects should stay in one data split for held-out evaluation.

## Construction

A task represents one complete feature: input → state → existing dependencies → observable outcome → lifecycle/reset. A valid start retains the original playable project and unrelated behavior. Remove the target mechanism and its necessary connections together. Prove reference feasibility before freezing a feature-ablation task; label extensions honestly inside the local authoring records.

The public instruction describes required behavior and necessary data interfaces, without prescribing the reference's private layout. Each mandatory check needs a public basis; every public requirement needs a validation outlet. Multiple changed files alone do not prove depth.

## Early fairness calibration

Before the expensive matrix, test likely observer failures: object discovery, fixtures, input geometry, timing, lifecycle, and result aggregation. A plausible legal implementation must remain accepted; a runnable targeted defect must be detected. Record justified not-applicable cases instead of inventing irrelevant tests.

## Stability and independent review

Run the reference, start baseline and start full checks with required repetitions. Check target and preserved behavior independently. Use relevant wrong controls and substantive legal controls; missing interfaces, crashes or timeouts are not interchangeable with behavioral failures. Review actual screenshots when visual requirements apply.

The independent reviewer first reads only the public package, then examines the entire grader and evidence. Keep original counterexamples through repair. Changes invalidate evidence only where the candidate/grader/runtime/spec fingerprints require it. Fix an observer coherently across its callers before regenerating its dependent matrix.

## Host replay and release

The host invokes the canonical public validator on the reference and both start modes, checks complete reports, expected exits, candidate identity and visual binding, then freezes the release inventory. An author's PASS assertion is not sufficient. A construction verdict does not establish K3/Qwen difficulty separation; that requires isolated solver experiments.

## Recovery

Keep one continuing author, finite budgets, fresh independent review, isolated XDG/display/runtime paths, and a process-level engine queue. Reuse only completed evidence whose full fingerprints match. Provider transport errors and exhausted review budgets retain their own status; do not turn them into semantic task failures. Stop admitting work at a model-invocation boundary when paused; do not kill unrelated processes.
