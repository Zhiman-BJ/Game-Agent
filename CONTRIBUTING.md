# Contributing

Keep task quality rules separate from scheduling and infrastructure recovery. Explain any change to public requirements, grader behavior or evidence invalidation. Add a focused regression for substantive runtime changes; use `python -m unittest discover -s tests -v` for portable host checks. Real model/engine integration requires a separate explicit preflight and fresh evidence.

Never commit API credentials, private provider payloads, task-author sessions, production configurations or generated experiment outputs. Keep source repository attribution and existing license files when distributing game assets. Do not represent finite controls as proof that a validator accepts every valid implementation.
